# Deprecations

MetaLayer documents removals and compatibility windows here as they are announced.

## Current posture (`1.0.0-beta`)

- Legacy TMDB Addon routes and compressed configuration import remain supported for the migration window (`AGENTS.md` §6.5). Removal requires a stable MetaLayer release, proven migration tooling, a documented support window, and a major-version announcement.
- Alpha → beta: schema compatibility is expected to stabilize; see `docs/versioning.md` and `docs/phase-m-exit.md` for explicit deferrals.

When a public contract is deprecated, add a dated entry in this file and a `CHANGELOG.md` note.
