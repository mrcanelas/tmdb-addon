# Appearance

Appearance Studio controls how metadata and artwork are presented. Artwork and localized text use Field Resolution Chains.

Configure UI: `/configure/appearance` (title, overview, poster, background builders). Shared builder: `ResolutionChainBuilder`.

Canonical sections: `AGENTS.md` §15. Field Resolution: `docs/field-resolution-chains.md`. Phase F exit: `docs/phase-f-exit.md`.
