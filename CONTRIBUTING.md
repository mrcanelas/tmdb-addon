# Contributing

MetaLayer is the successor to the TMDB Addon for Stremio.

Before contributing:

1. Read `AGENTS.md` (product rules, SemVer, PR expectations).
2. Follow Conventional Commits (`feat:`, `fix:`, `docs:`, `security:`, …).
3. Prefer one primary purpose per pull request.
4. Add `en-US` translation keys for user-facing text; update `pt-BR` / `es-ES` when required; run `pnpm i18n:check`.

Additional historical notes for the legacy addon tree live in `docs/contributing.md`. Runtime and architecture orientation: `docs/architecture.md`, `docs/development.md`.
